# Data notes

## Source
**DataCo Smart Supply Chain for Big Data Analysis** (Kaggle, public), dataset `shashwatwork/dataco-smart-supply-chain-for-big-data-analysis`:
https://www.kaggle.com/datasets/shashwatwork/dataco-smart-supply-chain-for-big-data-analysis
File used: `DataCoSupplyChainDataset.csv` (about 180k order lines, 53 columns, latin-1 encoded). Check the dataset page for its license and terms before you redistribute anything. This repo does **not** redistribute the file.

## What is committed
`data/sample/dataco_synthetic_sample.csv` is **SYNTHETIC** data: 200 made-up rows that use the same column names and value domains as DataCo. It is generated by `scripts/generate_sample.py` (seed 42), and every row carries `_synthetic=1`. Its numbers demonstrate the mechanics only and must not be read as findings.

## Using the real file
```bash
pip install kaggle   # requires your own Kaggle API token
kaggle datasets download -d shashwatwork/dataco-smart-supply-chain-for-big-data-analysis -p data/raw --unzip
make demo            # auto-detects data/raw/DataCoSupplyChainDataset.csv
# or: PYTHONPATH=src python -m oea.demo --data data/raw/DataCoSupplyChainDataset.csv --limit 20000
```
The loader validates the required columns and rejects any file that does not match.

## Field mapping
| Workflow concept | DataCo column(s) | Notes |
|---|---|---|
| Open order line | `Order Status` in PENDING, PENDING_PAYMENT, PROCESSING, ON_HOLD, PAYMENT_REVIEW, SUSPECTED_FRAUD | COMPLETE, CLOSED, and CANCELED are excluded |
| Credit hold | `Order Status` in ON_HOLD, PENDING_PAYMENT, PAYMENT_REVIEW | Proxy; DataCo has no credit master |
| Fraud review | `Order Status` = SUSPECTED_FRAUD | Human-only path |
| Late-delivery risk | `Late_delivery_risk`, `Days for shipping (real)`, `Days for shipment (scheduled)`, `Shipping Mode` | Slip = real − scheduled |
| Pricing mismatch | `Order Item Product Price`, `Order Item Quantity`, `Order Item Discount Rate`, `Order Item Total` | Discount above 20%, or total more than 2% off price × qty × (1 − disc) |
| Inventory shortfall | `Product Card Id`, `Order Item Quantity` | Lines with quantity of 3 or more are ATP-checked |

## Simulated (not in DataCo)
Credit limits, overdue days, on-hand stock, and next-receipt dates are **derived deterministically from ids** in `MockERP` and flagged `simulated: true`. In a real implementation they come from the ERP's credit management and ATP services.
